# pizzico-tauri

Shell nativa multipiattaforma basata su **Tauri 2** per generare l'APK Android (e build desktop / iOS).  
Condivide e ingloba gli asset web generati in `apps/web/dist` tramite WebView nativa senza overhead di runtime Chromium (dimensione APK di pochi megabyte).
