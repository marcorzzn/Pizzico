# pizzico-selection

Motore di selezione pixel, mascheratura e segmentazione interattiva del primo piano senza intelligenza artificiale.

## Riferimenti Scientifici (§6.3)
- **Segmentazione Foreground Multilivello**: Garcia, R. et al. *Real-time Interactive Foreground Extraction on Mobile Devices*, Graphics Interface 2015.
- **GrabCut Iterativo**: Rother, C., Kolmogorov, V., Blake, A. *“GrabCut” — Interactive Foreground Extraction using Iterated Graph Cuts*, ACM TOG (SIGGRAPH 2004).
- **Lazy Snapping**: Li, Y. et al. *Lazy Snapping*, ACM TOG (SIGGRAPH 2004).
