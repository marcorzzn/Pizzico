# pizzico-raster

Motore raster ad alte prestazioni con algoritmi deterministici e pipeline computazionali matematicamente verificate.

- **Median Filter O(1)**: Perreault, S. & Hébert, P. *Median Filtering in Constant Time*, IEEE TIP 2007.
- **Recursive Filtering**: Nehab, D. et al. *Constant-Time GPU Filter for Large-Kernel Blur and Summed-Area Tables*, SIGGRAPH Asia 2011.
- **Sparse Approximations**: Schuster, V. et al. *High-Performance Sparse Image Filtering*, PACMCGIT 2020.
- **Liquify (MLS)**: Schaefer, S. et al. *Image Deformation Using Moving Least Squares*, SIGGRAPH 2006.
