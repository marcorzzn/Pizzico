# pizzico-text

Motore tipografico professionale basato su `rustybuzz` (port completo in Rust di HarfBuzz).

## Riferimenti Scientifici e Standard (§6.4)
- **HarfBuzz / `rustybuzz`**: Motore di OpenType shaping multipiattaforma standard de facto dell'industria.
- **Supporto Script Complessi**: Legature standard e discrezionali, kerning contestuale, marcatura diacritica, supporto per script bidirezionali (RTL).
