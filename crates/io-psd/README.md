# pizzico-io-psd

Parser e scrittore per file in formato Photoshop (PSD / PSB), sviluppato in modalità **Clean Room** rigorosa basandosi esclusivamente sulla documentazione pubblica Adobe.

## Riferimenti (§6.5, §7)
- **Adobe Photoshop File Formats Specification**: [Adobe Developer Connection](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/)
- **PhotoCraft Reference**: Architettura open-source (MIT/Apache 2.0) di riferimento per la mappatura di layer records.
