# pizzico-commands

Registro centralizzato e serializzabile di tutti i comandi dell'applicazione (~700 API).  
Permette l'esecuzione da UI, scorciatoie da tastiera, Command Palette (⌘K) e macro automatizzate, assicurando tracciabilità e annullabilità sistematica.
