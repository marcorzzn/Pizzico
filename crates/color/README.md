# pizzico-color

Gestione scientifica del colore, spazi cromatici, OpenColorIO e 3D LUT adattive in tempo reale.

## Riferimenti Scientifici (§6.1)
- **3D LUT Adattive**: Zeng, H. et al. *Learning Image-adaptive 3D Lookup Tables for High Performance Photo Enhancement in Real-time*, IEEE TPAMI 2020.
- **Residual Interpolation Demosaicing**: Kiku, D. et al. *Residual Interpolation for Color Image Demosaicking*, IEEE TIP 2016.
- **OpenColorIO (OCIO)**: Open source standard per la gestione del colore nei media digitali.
